# Kay9 Hydro Tech Parking — website

Static landing page for Kay9 Hydro Tech Parking, Mumbai. Plain HTML, CSS and
JavaScript — no build step, no dependencies.

```
index.html     markup, inline SVG scene, specification dialogs
css/style.css  styles
js/            scroll sequence + navigation, dialogs, gallery
assets/        logo SVGs, brochure PDF, photographs
docs/          design and handover notes
```

To view locally, open `index.html` in a browser.

Outstanding items (company statistics, project list, enquiry form endpoint) are
listed in [docs/DESIGN-NOTES.md](docs/DESIGN-NOTES.md).
